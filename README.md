# Bento Grid - Projet de pratique Frontend

## Présentation du projet

Ce projet consiste en la réalisation d’une interface de type bento grid inspirée d’un thème de marketing social media et d’intelligence artificielle. L’objectif était de reproduire une maquette responsive à partir d’un brief fourni, en utilisant principalement HTML et CSS, puis d’optimiser la mise en page pour assurer une expérience cohérente sur mobile et sur desktop.

Le challenge a permis de travailler à la fois la structure sémantique du contenu, la composition visuelle et la gestion des layouts adaptatifs.

## Objectif du challenge

L’exercice visait à :

- reproduire aussi fidèlement que possible la maquette fournie ;
- construire une page responsive capable de s’adapter à plusieurs largeurs d’écran ;
- pratiquer la mise en page avec CSS Grid et Flexbox ;
- améliorer la compréhension du découpage HTML en sections logiques et du style associé.

## Démarches suivies

### 1. Analyse du brief et des documents fournis

La première étape a consisté à lire attentivement les documents du projet :

- le fichier README du challenge ;
- le guide de style avec les couleurs, typographies et dimensions attendues ;
- les assets et visuels déjà fournis.

Cette étape a permis de dégager les grandes lignes de la structure, les couleurs à utiliser et les différents blocs à intégrer dans la page.

### 2. Structuration du contenu en HTML

La page a ensuite été construite avec une structure HTML simple et claire. Chaque bloc visuel a été placé dans une section dédiée afin de faciliter la personnalisation CSS et de garder un code lisible.

Les sections principales ont été organisées autour de cartes illustratives représentant :

- une promotion autour de l’intelligence artificielle ;
- la gestion de plusieurs plateformes de réseaux sociaux ;
- la planification de contenu ;
- la croissance d’audience ;
- la création plus rapide de publications.

### 3. Mise en place du style de base

Une fois la structure en place, le travail a porté sur le style global de la page :

- définition de la couleur de fond générale ;
- application de la police DM Sans ;
- création d’une classe commune pour uniformiser les sections ;
- ajustement des marges, paddings et bordures arrondies.

Cette étape a permis de poser une base cohérente avant de travailler les détails visuels.

### 4. Stylisation mobile-first

Le projet a été conçu en priorité pour les petits écrans, conformément à une logique mobile-first. Chaque section a été stylisée pour être lisible et bien espacée sur mobile, avec des images et du texte adaptés à la largeur disponible.

Cette approche a permis de garantir une première version fonctionnelle et propre avant l’ajout des adaptations pour grand écran.

### 5. Adaptation au desktop avec CSS Grid

La partie la plus intéressante du projet a été la mise en page sur desktop. Une media query a été ajoutée pour transformer la disposition en une grille plus complexe, avec des zones dédiées à chaque section.

L’implémentation a permis de :

- organiser les blocs selon une composition proche de la maquette ;
- contrôler la position de chaque carte dans la grille ;
- gérer les espaces et les hauteurs de façon plus précise.

### 6. Ajustements visuels et raffinements

Enfin, plusieurs ajustements ont été réalisés pour améliorer la fidélité au design :

- mise à l’échelle des illustrations ;
- alignement des titres et du texte ;
- gestion de l’overflow et des hauteurs de sections ;
- amélioration de la cohérence visuelle entre les différents blocs.

## Apports et apprentissages

Ce projet a permis de développer plusieurs compétences importantes :

- meilleure compréhension de la structure HTML sémantique ;
- maîtrise plus solide du positionnement avec CSS Grid et Flexbox ;
- capacité à transformer un design en interface responsive ;
- sens accru de la cohérence visuelle et de la hiérarchie des contenus ;
- meilleure pratique de la séparation entre structure, style et contenu.

Il a aussi renforcé l’approche de travail par étapes : analyser, structurer, styliser puis ajuster en fonction du rendu final.

## Technologies utilisées

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Google Fonts (DM Sans)

## Résultat

Le projet aboutit à une page moderne et visuellement cohérente, composée de cartes colorées et d’illustrations, avec une présentation adaptée aux écrans mobiles comme aux grands écrans. Il constitue un bon exercice de consolidation des bases du développement front-end et de la mise en page responsive.
